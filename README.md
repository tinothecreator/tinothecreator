## 🌟 Featured Projects
 
### 🤟 [Deaf-Talks (SignStories)](https://github.com/tinothecreator/Deaf-Talks) · [Live demo](https://deaf-talks.vercel.app)
> **A platform where Deaf storytellers share South African Sign Language (SASL) stories and learners learn signs from them, with clear credit and consent.**
 
Built for the **OpenAI x Andela hackathon**. Deaf storytellers upload short signed stories, tag the key signs, and control exactly how their work is used. Learners watch the stories and tap individual signs to jump to that moment in the video.
 
**Key Features:**
- 🔐 Email/password authentication with database-enforced roles (Learner, Storyteller, Teacher)
- 🎥 Private video upload with direct-to-storage signed URLs, upload progress and server-side size/type checks
- 🏷️ Sign tagging with timestamps, so learners can seek straight to each sign
- ✅ Ownership, consent and usage controls with automatic credit and an audit history of changes
- 📖 Publish/withdraw workflow validated atomically in the database
- 🛡️ Row Level Security (RLS) policies with short-lived (5 min) playback URLs and no download action
- ♿ Mobile-first, keyboard-accessible UI with English captions
**Tech Stack:** Next.js (App Router), TypeScript, Tailwind CSS, Supabase (Auth, PostgreSQL, Storage, RLS), Zod, Vercel
